Understand your proxy pool

Magpie is a self-hosted proxy manager. You give it proxy addresses or webpages that list them. It checks those proxies repeatedly, records the results, and lets your applications connect through a rotating selection of healthy routes. The web dashboard and API manage the same workspace resources.

The whole workflow​

Magpie manages proxies you supply or discover. A successful import only means Magpie accepted the route. A successful check means it passed a particular workspace's validation at that time. Neither guarantees that every target website will accept traffic through it.
